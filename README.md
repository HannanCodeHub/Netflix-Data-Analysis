# 🎬 Netflix Data Analysis & Visualization Dashboard

A data analysis and visualization project based on the Netflix Titles dataset.  
The project explores Netflix's movies and TV shows through data cleaning, exploratory data analysis (EDA), and an interactive-style visualization dashboard built with Python and Matplotlib.

## 📊 Project Overview

This project analyzes Netflix content to discover patterns and insights related to:

- Movies vs TV Shows
- Content ratings
- Movie duration
- Top 10 directors
- Top 10 countries
- Top 10 genres
- Movies released per year
- TV Shows released per year

The final results are presented through a multi-chart Netflix-themed dashboard.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🧹 Data Cleaning

The dataset was cleaned before visualization by:

- Removing rows with missing values in important columns
- Handling missing ratings, countries, durations, and release years
- Separating movie duration into numerical values
- Splitting multiple countries and genres where required
- Preparing the data for visualization

## 📈 Visualizations

The dashboard contains eight visualizations:

1. **Movies vs TV Shows** – compares the number of movies and TV shows.
2. **Content Rating Distribution** – shows the distribution of Netflix content ratings.
3. **Movie Duration Distribution** – analyzes movie durations in minutes.
4. **Top 10 Directors** – identifies directors with the highest number of titles.
5. **Top 10 Countries** – shows countries with the highest number of Netflix titles.
6. **Top 10 Genres** – highlights the most common Netflix genres.
7. **Movies Released Per Year** – shows the yearly trend of movie releases.
8. **TV Shows Released Per Year** – shows the yearly trend of TV show releases.
